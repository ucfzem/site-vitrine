# Site Vitrine — Conversation Log

## What was built
Professional 3-page site template (Accueil, Services, Contact) with 4 languages and RTL support.

## Features
- 3 sections: Accueil (Home), Services, Contact
- 4 languages: FR (default), EN, ES, AR (Moroccan flag 🇲🇦)
- RTL support for Arabic
- Language switcher with flags
- Dark theme with gold accents
- Mobile responsive
- Contact form → opens email to ucfzem@gmail.com
- FOUC prevention for language

## Delivering to a client
1. Replace "VotreSociété" with client's company name
2. Update service descriptions
3. Replace email if needed
4. Update phone/hours in contact section

## Files
- `index.html` — Single-page app with all 4 languages
